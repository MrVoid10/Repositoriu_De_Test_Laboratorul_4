# Project Description – Mini Task Manager

## 1. Introducere

Mini Task Manager este o aplicație web simplă dezvoltată pentru gestionarea sarcinilor zilnice. 
Aplicația permite utilizatorului să adauge și să elimine task-uri într-o listă interactivă.

Scopul proiectului este demonstrarea utilizării unui sistem de control al versiunilor (Git) într-un proiect software mic, respectând bunele practici de organizare a repository-ului.

---

## 2. Scopul aplicației

Aplicația oferă o interfață simplă prin care utilizatorii pot:

- adăuga sarcini
- vizualiza lista de sarcini
- elimina sarcini finalizate

Proiectul servește drept exemplu pentru gestionarea codului sursă într-un mediu de dezvoltare software.

---

## 3. Funcționalități principale

Aplicația include următoarele funcționalități:

- introducerea unui task printr-un câmp de text
- adăugarea task-ului în lista de sarcini
- afișarea task-urilor într-o listă
- eliminarea task-urilor din listă
- validarea inputului (nu permite task-uri goale)

---

## 4. Tehnologii utilizate

Proiectul a fost realizat utilizând tehnologii web de bază:

- **HTML** – pentru structura paginii
- **CSS** – pentru stilizarea interfeței
- **JavaScript** – pentru logica aplicației
- **Git** – pentru controlul versiunilor
- **GitHub** – pentru repository remote
